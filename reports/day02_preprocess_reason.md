# Day 02 전처리 선택 이유 및 실험 보고서

## 1. 문제 정의

- **대상 이미지:** `samples/day02/challenge.jpg` (흰색 병뚜껑, 회색 배경)
- **핵심 문제:** 흰색 뚜껑과 회색 배경의 명암 차이(Contrast)가 매우 적고 전반적으로 어두워,
  단순 Otsu 이진화 적용 시 뚜껑과 배경이 분리되지 않음
- **목표:** Otsu 이진화를 통해 뚜껑 외곽선을 배경으로부터 완벽하게 분리

---

## 2. 1차 시도 — Gamma 보정 (실패)

### 적용 기법
- `gamma = 0.5` (어두운 영역 밝기 증가)

### 실패 원인 분석

```
[문제 구조]
뚜껑 상단 (밝음) ──────────── 배경 (중간 밝기)
뚜껑 하단 그림자 (어두움) ───  ← 이게 문제

Gamma 보정 적용 시:
  → 어두운 '하단 그림자'가 밝아짐
  → 히스토그램이 중간값으로 압축됨
  → Otsu가 뚜껑 상단 / 배경 경계를 정확히 찾지 못함
  → 뚜껑 상단이 배경으로 통합되어 외곽선 소실
```

**결론:** Gamma는 전역(Global) 밝기 보정이라, 뚜껑 내부의 국소적 명암 불균일을 오히려 악화시킴

---

## 3. 2차 시도 — CLAHE + Sharpening + Otsu (성공)

### 선택 이유

| 기법 | 역할 | 선택 근거 |
|------|------|-----------|
| **CLAHE** | 국소 히스토그램 균일화 | 뚜껑 영역별로 독립적으로 대비 강화 → 그림자에 영향받지 않음 |
| **Sharpening** | 경계선 강조 | CLAHE 후에도 약한 나사산/홈 경계를 더 뚜렷하게 만듦 |
| **Otsu** | 자동 이진화 | 대비가 충분히 확보된 후에는 자동 임계값이 최적점을 정확히 찾음 |

### 적용 파라미터

```python
# CLAHE
clahe = cv2.createCLAHE(clipLimit=3.0, tileGridSize=(8, 8))

# Sharpening Kernel (3x3)
kernel = np.array([[-1, -1, -1],
                   [-1,  9, -1],
                   [-1, -1, -1]])

# Otsu 이진화
_, binary = cv2.threshold(sharpened, 0, 255,
                          cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

### 파라미터 선택 근거

- `clipLimit=3.0`: 2.0보다 높여서 대비를 강하게 증폭. 4.0 이상은 노이즈 과증폭 우려
- `tileGridSize=(8,8)`: 이미지 크기 대비 적절한 타일 크기. 너무 작으면 아티팩트 발생
- `center=9 kernel`: 주변 8픽셀 합(-8) + 중심(9) = 순이득 +1로 원본 밝기 유지하며 엣지 강조

## 5. Day 03 연결 계획

현재 이진화 결과의 **잔존 문제:**

```
1. 뚜껑 내부 홀(Holes) — 이진화 후 내부 검은 점 산재
2. 배경 누출 — 상단 배경 일부 흰색으로 분류
3. 하단 노이즈 — 병목 부분 파편화
```

**Day 03 해결 순서:**

```
Binary Image
    ↓
Morphology Opening  → 작은 노이즈 제거 (kernel 3x3, iter=1)
    ↓
Morphology Closing  → 내부 홀 메우기 (kernel 5x5, iter=2)
    ↓
findContours        → 외곽선 추출
    ↓
면적 필터링         → 최대 Contour = 뚜껑 본체
    ↓
OK / NG 판정        → 면적, 위치, 종횡비 기반
```
